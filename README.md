# Heap agent plugins

Plugins that connect AI agents to Heap, a note library that saves anything and organizes it for you.

| Plugin               | What it does                                                                                    |
| -------------------- | ----------------------------------------------------------------------------------------------- |
| [heap](plugins/heap) | Claude Code plugin: look up what you saved, save notes, links and chat recaps from Claude Code. |

## Install

In Claude Code:

```
/plugin marketplace add Manifold-Apps/heap-agent-plugins
/plugin install heap@heap-agent-plugins
```

Then sign in once. See [the plugin README](plugins/heap/README.md) for the details.
